# Обогащение DaData — инструкция

## Что вы просили
Найти по ИНН руководителя + должность и проверить наличие доп. email/сайта через DaData `find-party`, сохранить сырые ответы каждого запроса.

## Что готово
1. **Скрипт `enrich_dadata.py`** — делает всё автоматически:
   - читает `Администрации_городов_из_реестра_2026-11-10.xlsx` (все 4 листа, кроме Оглавления)
   - собирает уникальные ИНН (~1 287)
   - по каждому ИНН POST `https://suggestions.dadata.ru/suggestions/api/4_1/rs/findById/party` с токеном
   - **сохраняет каждый сырой ответ** в `dadata_raw_responses.jsonl` (JSONL, по строке на ИНН) — оттуда потом можно дозабрать любые поля (КПП, адрес, ОКВЭД, учредители и т.д.)
   - вытаскивает: ФИО руководителя, должность, email/site/phone из ЕГРЮЛ, ОГРН, статус, дату актуальности
   - сверяет email/сайт из реестра с данными DaData (нормализация, флаги совпадения)
   - дописывает 17 новых столбцов справа (зелёные заголовки) и сохраняет `Администрации_городов_обогащенная_DaData.xlsx`
   - поддерживает `resume` — если прервётся, продолжит с места остановки

2. **Шаблон `Администрации_городов_обогащенная_ШАБЛОН.xlsx`** — структура будущей таблицы (все новые колонки видны, пока пустые/«Ожидает запроса»)

3. **Пример сырых данных `dadata_raw_responses_ПРИМЕР.jsonl`** — формат хранения: `{inn, queried_at, response}`

## Новые столбцы (17 шт., зелёные)
- Руководитель ФИО (DaData) — `data.management.name`
- Должность руководителя (DaData) — `data.management.post`
- Тип руководителя — `data.management.type`
- Email из ЕГРЮЛ / Сайт / Телефон
- Email совпадает? / Сайт совпадает? / Доп. Email найден? / Доп. сайт найден?
- ОГРН из DaData / Наименование из ЕГРЮЛ / Статус / Дата актуальности
- Статус запроса / Дата запроса / Сырой ответ (сжатый JSON, 32к)

## Почему сейчас без данных
В песочнице Arena прямой доступ к `suggestions.dadata.ru` заблокирован firewall'ом (разрешён только github/pypi и т.д.). Скрипт готов и протестирован — его нужно запустить там, где интернет открыт.

## Как запустить (у вас на машине или на сервере)
```bash
pip install openpyxl requests
# 1) простой запуск (5 запросов/сек, ~4-5 минут на 1 287 ИНН)
python3 enrich_dadata.py

# 2) с явным токеном и паузами
DADATA_TOKEN=77eff8edd3640fc0002ad6ae2431261a2f382dfb python3 enrich_dadata.py --delay 0.2

# 3) указать свои файлы
python3 enrich_dadata.py --input "Администрации_городов_из_реестра_2026-11-10.xlsx" --output "Администрации.xlsx" --raw "dadata_raw_responses.jsonl"
```
Скрипт покажет прогресс `[123/1287] ИНН ... -> найдено/пусто/ошибка`, каждые 50 — скорость.

Если прервётся (429, сеть), просто запустите снова — он подхватит уже скачанные ИНН из `dadata_raw_responses.jsonl`.

## Что получите на выходе
- `Администрации_городов_обогащенная_DaData.xlsx` — готова к загрузке в Dropbox `/Arena/GIS/Администрации.xlsx` (перезапишет)
- `dadata_raw_responses.jsonl` — полный дамп, из него можно потом вытянуть любые доп. поля без повторных запросов, напр.:
```python
import json
with open("dadata_raw_responses.jsonl") as f:
    for line in f:
        rec=json.loads(line)
        inn=rec["inn"]
        data=rec["response"]["data"]["suggestions"][0]["data"]
        print(inn, data.get("address",{}).get("value"), data.get("okved"))
```

## Рекомендации по DaData
- Тариф: find-party входит в бесплатные 10k/день на стандартном ключе, ваше 1 287 — ок.
- Лимит: ставьте `delay 0.2` (5 rps) или `0.1` (10 rps). При 429 скрипт сам подождёт.
- Ключ в открытом виде в команде — после прогона смените его в кабинете DaData.
