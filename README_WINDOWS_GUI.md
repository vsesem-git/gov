# DaData Парсер Администраций — Windows GUI

Графический интерфейс для парсинга администраций городов через DaData Find-Party.

## Что делает
- Берёт `Администрации_городов_из_реестра_2026-11-10.xlsx` (5 листов, 1327 уникальных ИНН)
- По каждому ИНН стучит в `POST https://suggestions.dadata.ru/suggestions/api/4_1/rs/findById/party` с вашим токеном `77eff8edd3640fc0002ad6ae2431261a2f382dfb`
- Вытаскивает: **руководитель ФИО + должность**, email/сайт/телефон из ЕГРЮЛ, ОГРН, статус, дату актуальности
- Сверяет email/сайт из реестра с ЕГРЮЛ: флаги *Совпадает? / Доп. найден?*
- **Сохраняет КАЖДЫЙ сырой ответ** в `dadata_raw_responses.jsonl` (JSONL: `{inn, queried_at, response}`) — оттуда потом дозаберёте любые поля (адрес, ОКВЭД, учредители, уставной капитал и т.д.) без повторных запросов
- Дописывает 15 новых зелёных колонок в Excel, включает фильтры/печать

## Интерфейс

- **Входной Excel** — по умолчанию `Администрации_городов_из_реестра_2026-11-10.xlsx` (кнопка Обзор)
- **Выходной Excel** — `Администрации_городов_обогащенная_DaData.xlsx` (зелёные колонки справа)
- **Сырые ответы** — `dadata_raw_responses.jsonl` (1 строка = 1 ИНН)
- **DaData токен** — предзаполнен вашим ключом, можно заменить; кнопка *Проверить* шлёт тестовый запрос
- **Пауза** — 0.15–0.20 сек = 5–6 запросов/сек (защита от 429 Too Many Requests)
- **Resume** — если прервалось (свет, интернет), включите галочку и запустите снова — пропустит уже скачанные ИНН
- **Прогресс** — Всего / Готово / Найдено / Ошибок + прогресс-бар + лог + таблица последних 50
- **Тест 1 запроса** — проверяет ИНН `5902290635` (Администрация Перми: Соснин Эдуард Олегович — Глава города Перми)

## Новые колонки (15 шт.)

| № | Колонка | Источник DaData |
|---|---------|-----------------|
| 1 | Руководитель ФИО | `data.management.name` |
| 2 | Должность | `data.management.post` |
| 3 | Email из ЕГРЮЛ | `data.email` |
| 4 | Сайт | `data.site` |
| 5 | Телефон | `data.phone` |
| 6 | Email совпадает? | сравнение нормализованных email |
| 7 | Сайт совпадает? | сравнение без `https://www.` |
| 8 | Доп. Email найден? | `Да` если в ЕГРЮЛ другой email |
| 9 | Доп. сайт найден? | `Да` если другой сайт |
| 10 | ОГРН из DaData | `data.ogrn` |
| 11 | Наименование из ЕГРЮЛ | `unrestricted_value` |
| 12 | Статус | `data.state.status` (ACTIVE/LIQUIDATING/LIQUIDATED) |
| 13 | Дата актуальности | `state.actuality_date` |
| 14 | Статус запроса | Найдено / Не найдено / Ошибка N |
| 15 | Дата запроса | `YYYY-MM-DD HH:MM` |

## Сырые ответы — как дозабрать доп. поля

Каждая строка в `dadata_raw_responses.jsonl`:
```json
{"inn":"5902290635","queried_at":"2026-11-12T10:00:00","response":{"http_status":200,"data":{"suggestions":[{"value":"АДМИНИСТРАЦИЯ ГОРОДА ПЕРМИ","data":{"inn":"5902290635","ogrn":"1025900532460","address":{"value":"614000, Пермский край, г. Пермь, ул. Ленина, д. 23"},"okved":"84.11.35","management":{"name":"Соснин Эдуард Олегович","post":"Глава города Перми"},...}}]}}}
```

Пример дозабора:
```python
import json
with open("dadata_raw_responses.jsonl", encoding="utf-8") as f:
    for line in f:
        rec = json.loads(line)
        inn = rec["inn"]
        sugg = rec["response"].get("data", {}).get("suggestions", [])
        if not sugg: continue
        d = sugg[0]["data"]
        print(inn, d.get("address",{}).get("value"), d.get("okved"), d.get("kpp"))
```

Доступные поля: `kpp`, `address`, `okved`, `okveds`, `founders`, `managers`, `capital`, `documents`, `licenses` и т.д. — полный список в [документации](https://dadata.ru/api/find-party/#response).

## Лимиты DaData

- Ваш тариф: **Find-Party** входит в бесплатный лимит 10 000/день (стандарт). 1327 ИНН — укладывается.
- При `429 Too Many Requests` скрипт сам ждёт `2^attempt` секунд и ретраит.
- Рекомендуемая пауза `0.15` (6.5 r/s) — оптимально для баланса скорость/лимиты.

## Troubleshooting

- **Python не найден** — установите с https://python.org, галочка *Add Python to PATH*
- **openpyxl/requests не ставятся** — запустите `pip install openpyxl requests --user`
- **Кириллица в путях** — поддерживается, но избегайте OneDrive-синхронизируемых папок при больших файлах
- **401/403** — проверьте токен в кабинете https://dadata.ru/profile/#info (скопируйте новый)
- **Пусто в DaData** — для 10–15% муниципальных учреждений email/сайт в ЕГРЮЛ не указан — это нормально, флаг покажет `Пусто в DaData`
