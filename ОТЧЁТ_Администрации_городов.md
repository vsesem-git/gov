## Как использовать
- Отфильтруйте по столбцу L «Административная территория» для выборки по региону (ОКТМО)
- Отфильтруйте по M «Статус функции» = «Подтверждено» для действующих
- Столбец H «Официальный сайт» + I/J контакты — для связи

Если нужно уточнить фильтр (например, только миллионники, только ЦФО, только подтверждённые) — скажите, пересоберу.
